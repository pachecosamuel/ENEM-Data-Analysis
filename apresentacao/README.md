# Apresentação

Abra `visao_geral_2025.ipynb` para ler a história e conferir a tabela. Os PNG finais ficam em `graficos/`. Reexecute com o kernel do projeto; o notebook usa funções de `src/` e consulta trusted, sem ler raw. Cópias externas conservam saídas para leitura, mas dependem deste projeto para executar.

Textos curtos, fatos verificáveis e gráficos simples orientam as próximas entregas. Não confundir extremos observados com limites teóricos, nem comparação descritiva com causalidade.
