# Apresentação

Abra `visao_geral_2025.ipynb` para ler a história e conferir a tabela. Os PNG finais ficam em `graficos/`. Reexecute com o kernel do projeto; o notebook lê agregados/auditorias, confere seus hashes e o da trusted e usa funções de gráficos de `src/`, sem ler raw nem executar pipelines. A narrativa segue inscritos → dias → transições → áreas → redação → local de prova → rede escolar → perfil econômico independente. Cópias externas conservam saídas para leitura, mas dependem deste projeto para executar.

Textos curtos, fatos verificáveis e gráficos simples orientam as próximas entregas. Não confundir extremos observados com limites teóricos, nem comparação descritiva com causalidade.
